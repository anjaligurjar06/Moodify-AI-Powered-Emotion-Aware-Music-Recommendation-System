# 🎵 Moodify

### AI-Powered Emotion-Aware Music Recommendation System

Moodify is an intelligent music recommendation platform that understands how you feel and curates playlists accordingly.

Instead of manually searching for songs, Moodify uses Artificial Intelligence to detect your emotions through facial expressions, text input, or voice, then generates personalized playlists that match—or even improve—your mood.

Whether you're feeling happy, stressed, relaxed, or sad, Moodify helps you discover the perfect soundtrack for every moment.

##  Workflow

1. User signs in.
2. Webcam captures facial expressions *(or user enters text)*.
3. AI predicts the user's emotion.
4. Recommendation engine maps emotion to music preferences.
5. Spotify API fetches matching tracks.
6. Playlist is displayed instantly.
7. Mood history is saved for future insights.
